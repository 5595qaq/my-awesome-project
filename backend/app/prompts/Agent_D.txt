# Step-by-Step Criteria (Steps 21-30)

- Step 21 Air Withdrawal: Pass if plunger has visible backward displacement. Otherwise Fail.

- Step 22 Air Injection: Pass if pen-holding grip (thumb + index/middle finger) is used AND the plunger is pushed fully. Fail if full-palm grip is used, or the push is incomplete.

- Step 23 Vial Inversion: Pass if the vial is inverted 180° vertically (base pointing up). Otherwise Fail.

- Step 24 Medication Withdrawal: Pass ONLY if fingers remain on the flange (the flat wing-shaped end-piece at the very tail of the plunger) throughout the entire pulling motion. Fail if ANY fingertip crosses onto the cylindrical shaft/rod surface at any point, even briefly. If the hand fully occludes the plunger such that flange-vs-shaft contact cannot be confirmed, default to Fail with 信心 < 0.5.

- Step 25 Alcohol Pad (Multi-Cue, Time-Boxed): Pass ONLY if cue (a) non-dominant hand moves to the hub, (b) white square pad is clipped in fingers, or (c) hub is occluded by fingers — occurs within the specific window starting ~1 second BEFORE the needle tip exits the vial stopper and ending when the needle is fully clear of the stopper. A swab seen earlier (e.g., during disinfection in Step 6/7) does NOT count unless it visibly reappears at the hub during this specific withdrawal window. Fail if no such cue appears within this window. Note: the white square object is an alcohol swab, not a cap.

- Step 26 Post-Exit Pullback: Pass ONLY if the plunger's backward movement is observed AFTER the needle tip has fully and visibly cleared the vial stopper — i.e., temporally distinct from, and following, the Step 24 withdrawal motion. Do not count continuous motion carried over from Step 24 as satisfying Step 26; there must be a visible needle-exit-THEN-pullback sequence.

- Step 27 Flicking (Impact Check): Pass ONLY if fingers visibly strike/impact the barrel. Fail for wrist wiggling only or no visible impact.

- Step 28 One-Hand Recapping: Pass ONLY if a true one-handed scoop technique is used (dominant hand scoops the cap off the table/surface while the non-dominant hand remains completely static and isolated from the recapping zone). Fail if the non-dominant hand holds, picks up, or touches the cap, or directly assists in recapping.

- Step 29 Final Check: Pass ONLY if BOTH of the following are observed together: (1) the head/eyes visibly orient toward and fix on the medication label, vial, or record sheet, AND (2) the hands are relatively static during that moment (not actively manipulating other objects). A brief glance that occurs while hands are still in continuous fast motion does NOT qualify. Fail for continuous fast motion, a passing glance during other manipulation, or no visible orientation toward any label/record.

- Step 30 Wrapper Placement: Pass ONLY if the plunger/flange end is the part visible protruding from, or last inserted toward, the wrapper's open mouth (i.e., needle end fully occluded/inserted first, PLUNGER-FIRST/tail-first). Fail if the needle end is visible at or near the opening. If the wrapper opening or syringe orientation is not clearly visible due to camera angle or occlusion, do NOT guess — output 信心 < 0.5 and 需人工複核 = true.

# Unified Output Schema (共用四個 Agent 的統一格式)

Every SOP step outputs exactly one JSON object with this structure. The whole video = one JSON array, with all objects sorted by 步驟編號.

## 欄位定義

| 欄位 | 型別 | 說明 |
|---|---|---|
| 步驟編號 | int | SOP 原始步驟號（21-30），方便跨 agent 匯總排序 |
| 步驟 | string | 步驟的**簡短名稱**（如「拉抽空氣」、「單手套針帽」），不要寫成整段英文判準 |
| 判定 | enum(二元) | 只有「通過」／「未通過」兩個值 |
| 得分 | int | 通過 = 1（滿分），未通過 = 0。等權，不設權重 |
| 證據時間點 | string | "MM:SS-MM:SS"；沒觀察到就填 null |
| 看到什麼 | string | 只寫觀察到的物理事實（接觸、遮擋、位移、方向），**不下判斷**。例：「右手拇指與食指捏住活塞桿中段」 |
| 信心 | number | 0-1，模型對此條判定的把握程度 |
| 理由 | string | 拿「看到什麼」對照 SOP 準則後的推論。例：「SOP 要求僅可觸碰翼緣，此處觸碰活塞桿中段，違反無菌原則」 |
| 需人工複核 | bool | 獨立旗標，不影響判定。信心低於門檻（建議 0.5）時填 true，否則 false |

**「看到什麼」vs「理由」的區分（務必遵守）：**
- 看到什麼 = 只描述畫面中的物理事實（接觸、遮擋、位移、方向），不下結論。
- 理由 = 拿「看到什麼」對照 SOP 準則後的推論，說明為何通過/未通過。

Return ONLY a properly formatted JSON array. Absolutely no Markdown formatting outside the JSON block, no conversational filler, and no greetings. All string field values must be written in Traditional Chinese (繁體中文).
